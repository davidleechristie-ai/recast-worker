A JSON converter that never uploads your data

If the JSON you're converting has customer names, email addresses, API keys, or anything else you wouldn't want sitting on a stranger's server — even briefly — this matters more than it might seem. Most "free online JSON converter" tools work by sending your pasted data to a backend server, running the conversion there, and sending the result back. Recast doesn't do that step at all.

What "runs in your browser" actually means

The conversion — JSON to CSV, XML, YAML, or back — happens entirely in JavaScript, inside the same browser tab you're looking at right now. There's no upload button because there's nothing to upload: your data never becomes a network request. You can disconnect from the internet after the page loads and the tool still works.

A real example

JSON → CSV

Before
[
  {
    "customer": "Ada Lovelace",
    "email": "ada@example.com",
    "total": 249.99
  }
]
After
customer,email,total
Ada Lovelace,ada@example.com,249.99

Common questions

How can I check this is actually true, not just a claim?

Open your browser's developer tools, go to the Network tab, and run a conversion. You'll see no request carrying your pasted data anywhere — because none is made.

Does this work for CSV and XML too, or just JSON?

All conversions between JSON, CSV, XML, and YAML run the same way — entirely client-side, regardless of which formats are involved.

What about the paid Pro features — do those upload data?

No. Pro raises file size and batch limits; it doesn't change where the conversion happens. The only thing that ever leaves your browser is the checkout process itself, handled directly by Stripe.

Is there a file size limit?

The free tier handles files up to 3 MB. Pro raises that to 25 MB and adds batch conversion for multiple files at once.
