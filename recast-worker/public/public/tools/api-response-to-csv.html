Example: turn a nested API response into CSV

An API may return nested customer data like this:

{
  "id": 42,
  "customer": {"name": "Ada", "city": "London"},
  "total": 125.50
}

Flattening the nested object creates stable CSV columns such as customer.name and customer.city. The result can then be downloaded as a spreadsheet-friendly CSV without writing a one-off script.

API response to CSV questions

Can I convert a nested JSON API response to CSV?

Yes. Flatten nested objects first so nested values become predictable columns, then convert the flattened JSON to CSV.

Do I need to call the API directly from Recast?

No. You can paste a captured JSON response into the browser tool. Recast's hosted API and Automation features are separate options when you explicitly want server-side execution.

What if the response contains arrays?

Arrays need a deliberate export strategy because one API record can contain several child records. Depending on the data, you may keep an array value, flatten indexes, or reshape the data before CSV export.
