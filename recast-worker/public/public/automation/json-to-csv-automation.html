When this is useful

Use this workflow when the same data task keeps coming back: a report, integration, export, validation step or hand-off between systems. Build the transformation once, test it with your own data, then choose whether to run it manually, expose it as an endpoint or schedule it.

How it works

3

Automate it

Deploy the workflow, connect HTTPS inputs or webhooks and choose a schedule.

Privacy and hosted execution

Recast's normal browser tools process data locally. Hosted Automation is different: only workflows and data you explicitly choose to deploy are processed by the hosted workflow service. Authenticated connectors use the encrypted credential vault.
