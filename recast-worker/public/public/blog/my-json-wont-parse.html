My JSON Won't Parse — Here's How to Actually Find the Error

Scanning a broken JSON file by eye, line by line, looking for the one missing comma is a genuinely bad way to spend ten minutes. A parser already knows exactly where it stopped — the trick is getting it to tell you, rather than just saying "invalid JSON" and leaving you to search. Here are five real, common mistakes, and the exact message Recast's validator gives for each — genuine output, not paraphrased.

1. A trailing comma

{
  "name": "Ada",
  "role": "Engineer",
}

Error: Expected double-quoted property name in JSON at position 35 (line 1 column 36)

That trailing comma after "Engineer" is the single most common JSON mistake there is — it's valid in JavaScript object literals, but not in JSON itself.

2. A missing comma between fields

{
  "name": "Ada"
  "role": "Engineer"
}

Error: Expected ',' or '}' after property value in JSON at position 15 (line 1 column 16)

The position tells you exactly where the parser gave up — right after "Ada", where it expected either a comma (more fields coming) or a closing brace (that was the last one).

3. An unquoted key

{
  name: "Ada"
}

Error: Expected property name or '}' in JSON at position 1 (line 1 column 2)

Also valid JavaScript, not valid JSON. Every key needs double quotes — not single quotes, not no quotes at all.

4. Single quotes instead of double quotes

{
  'name': "Ada"
}

Error: Expected property name or '}' in JSON at position 1 (line 1 column 2)

Same underlying problem as the unquoted key above — JSON's grammar only recognizes double quotes as marking a valid property name.

5. A missing closing brace

{
  "name": "Ada"

Error: Expected ',' or '}' after property value in JSON at position 14 (line 1 column 15)

The file just stops. This one's easy to introduce by accident when copy-pasting a fragment of a larger response.

What these messages actually are, honestly

These are the real error messages from the JavaScript engine's own JSON parser, surfaced directly — not a custom, rewritten-for-humans translation layer. What Recast adds is showing you this clearly, with the exact line and column, right next to your input, instead of you having to open a separate console or guess. For the five mistakes above, that's usually enough to fix it in seconds rather than minutes.
