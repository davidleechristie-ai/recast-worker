Recast API

The same conversion, diff, and schema engine behind the browser tool, over HTTP. No separate SDK, no separate key-management system — the access token issued when you subscribe to the API plan doubles as your API key.

Authentication

Every request needs an Authorization: Bearer <token> header. Requests without one get a clear, real error back:

$ curl -X POST https://tryrecast.app/v1/convert \
  -H "Content-Type: application/json" \
  -d '{"mode":"json2csv","input":"[...]"}'

HTTP/1.1 401 Unauthorized
{
  "error": "missing Authorization: Bearer <token> header"
}

Note: this requires a token from the API plan specifically — a Pro or day-pass token is valid for the browser tool but returns 403 here.

A real example

Converting a JSON array to CSV:

$ curl -X POST https://tryrecast.app/v1/convert \
  -H "Authorization: Bearer <your-token>" \
  -H "Content-Type: application/json" \
  -d '{
    "mode": "json2csv",
    "input": "[{\"id\":101,\"status\":\"shipped\",\"customer\":{\"name\":\"Ada Lovelace\",\"country\":\"UK\"}}]"
  }'

Returns:

{
  "output": "id,status,customer.name,customer.country\n101,shipped,Ada Lovelace,UK",
  "usage": {
    "calls_this_month": 1,
    "limit": 10000
  }
}

Every response includes your current usage against the monthly limit — no separate endpoint needed to check it.

Endpoints

POST /v1/convert

Body: { mode, input, options }. Modes: json2csv, csv2json, json2xml, xml2json, flatten, unflatten, json2yaml, yaml2json, json2markdown, markdown2json.

POST /v1/diff

Body: { mode, inputA, inputB, options }. Modes: diffCsv, diffJson, diffXml.

POST /v1/schema

Body: { input, options }. Infers a JSON Schema from a real JSON sample — the same engine behind the Schema Generator tool.

Limits

10,000 calls per calendar month, resetting automatically at the start of each month — no manual reset needed. Rate-limited requests get a plain 429 with a clear error message, not a silent failure.

Common questions

Do I need a separate API key from my account?

No — the same token you get when subscribing to the API plan is your API key. There's no separate dashboard or key-generation step.

Is there a CLI too, for scripts that don't want to call the HTTP API directly?

Yes — recast-cli runs the identical engine locally, with no network calls at all, which also makes it safe to use in CI on files containing secrets.

What happens if I go over my monthly limit?

Further calls return a 429 with the exact limit and a note that it resets next calendar month — nothing is charged automatically for overage.

Hosted Workflows

Deploy a saved Recast recipe once, then execute the same pipeline through a stable authenticated endpoint.

POST /v1/workflows
Authorization: Bearer <api-token>

{
  "workflow": {
    "name": "Customer export",
    "steps": [
      {"mode":"transformRemove","params":{"paths":["internal_id"]}},
      {"mode":"json2csv","params":{}}
    ]
  }
}

Run the deployed workflow with POST /v1/workflows/{id}/run and a string input. Configure scheduled execution with POST /v1/workflows/{id}/automation using hourly, daily or weekly. Retrieve recent executions from GET /v1/workflows/{id}/history.

Hosted workflows are an API-plan beta. Browser tools remain client-side; only workflows and inputs explicitly deployed for hosted execution are stored server-side.
