Tools

Every data tool Recast offers, in one place

23 free, browser-based tools for JSON, CSV, XML, YAML and Markdown. Nothing is uploaded — every tool below runs entirely in your browser, no signup required.

Convert

JSON to CSV ConverterAuto-flattens nested objects and arrays, Excel-ready output. CSV to JSON ConverterAutomatically detects numbers, booleans, and nested structure. JSON to XML ConverterHandles nested objects and arrays correctly. XML to JSON ConverterHandles attributes and repeated tags. JSON to YAMLHandles nested objects and arrays. YAML to JSONParses mappings, sequences, and anchors. JSON to Markdown TableGitHub-flavored Markdown table output. Markdown Table to JSONConverts a Markdown pipe table back into JSON.

Transform

Flatten Nested JSONTurns deep nesting into dot-notation key-value pairs. Unflatten JSONConverts flat dot-notation keys back into a nested object.

JSON ValidatorExact line and column, right next to your input. JSON FormatterBeautify or minify JSON, entirely in your browser. Validate JSON Against a SchemaChecks JSON data against a JSON Schema (draft-07 subset).
