What's new in Recast: graphs, recipes, offline mode, and a real demo

Recast started as a converter — JSON to CSV, and back. It's grown a lot since then, faster than the homepage alone can explain. This is a catalog of what's shipped recently, in plain terms: what each thing does, and why it's there.

An actual visual graph for JSON

Reading deeply nested JSON as raw text gets hard fast. Graph view renders your JSON as an interactive, collapsible node tree instead — click any object or array to fold it away, color-coded by type, connected with real edges rather than indentation you have to trace by eye. It's on both the input and output panels, sitting right next to the existing table view for CSV.

Recipes — chain steps, save the pipeline

A lot of real conversion work isn't one step. Flatten, then sort keys, then convert to CSV. Recipes let you build that chain once, run it as a single action, and save it with a name so it's there next time — up to 8 steps, each one feeding its output into the next. It's a free feature, not gated behind Pro, since a single saved pipeline isn't the same kind of usage as batch-processing hundreds of files.

Live schema validation, as you type

The schema validator used to be click-a-button-see-a-report. Now, in Validate-against-Schema mode, a small badge updates live as you edit — a green check, or a red count of exactly how many issues your data has against the schema — closer to how a real IDE behaves than a static form.

Batch diff — not just batch convert

Batch conversion already handled "run this transform on 100 files." Now the diff tools do too: drop a folder of "before" files and a folder of "after" files, and Recast pairs them up by matching filename and runs the same key-aware diffing across every pair at once, downloadable as a single zip of results.

Eleven languages now, from one schema

JSON → Schema infers a schema from a real sample, and that same schema now drives eleven different outputs: TypeScript, Zod, Python, Pydantic, Go, Kotlin, Rust, Java, Swift, C#, and SQL CREATE TABLE statements. Java comes out as modern records, not classic JavaBean boilerplate. Swift structs conform to Codable. C# includes [JsonPropertyName] attributes so PascalCase properties still map correctly to your original JSON keys. SQL is the odd one out in a useful way — arrays of objects become their own linked child tables with a real foreign key, rather than trying to cram a list into a single column. All eleven share the same inference engine, so a Go struct and a C# class generated from the same JSON always agree with each other.

Mock data, generated from a schema

Need realistic-looking test data and don't have any? JSON → Mock data infers a schema from a sample, then generates however many records you ask for — field-name heuristics fill in sensible values (an email field gets a real-looking email, a city field gets an actual city), all computed locally, no AI involved.

Export the graph view as an image

Graph view already turned nested JSON into a collapsible, interactive tree. Now there's a download option sitting right on the graph itself — SVG for something you'll edit or embed cleanly at any size, PNG for something you can just drop straight into a doc or a Slack message. Both export exactly what's currently expanded or collapsed, so you can fold away the noise first and export just the part that matters.

A light theme, for anyone who wants one

Recast was dark-only until now. There's a toggle in the header — the sun/moon icon next to Share link — that switches instantly and remembers your choice for next time. It's a real second theme, not an inverted filter: backgrounds, panels, and text all have their own proper light-mode values, checked for the same contrast a dark-mode user gets.

A command palette for everything else

With more than two dozen tools now, hunting through the nav gets old. Cmd/Ctrl + K opens a searchable palette — type a few letters of what you want ("kotlin", "diff", "yaml") and jump straight there.

It works with no internet connection

Recast is now a proper installable app — add it to your home screen or app dock from the browser's own install prompt, and it keeps working with zero network connection. This isn't a native download; it's a web standard (a service worker) doing the same job, tested by actually disconnecting and running a real conversion offline.

A demo page with real, full-sized data

Trying out a data tool usually means either pasting in something of your own (not always something you want to hand a stranger's website, even one that says it doesn't upload anything) or typing three fake rows that don't show you how the tool handles anything real. The Demo page exists to skip both problems: real, full-sized generated datasets — 2,500 nested e-commerce orders, a 4,000-row employee CSV, 2,500 XML log events, 150 YAML service configs, and a genuine before/after order-status pair for the diff tool — that you can drag straight onto the converter or the API playground, or just tap to load. Nothing to make up, nothing of your own at risk.

A guide for people who aren't developers

Recast was built for people who already know what JSON and CSV are. Not everyone does, and there's no reason the tool should only be useful to people who do. The How To guide walks through the whole thing in plain language — what the tool actually does, a step-by-step first conversion with real screenshots, and an honest explanation of when (and whether) you'd ever need the API.

Most of this is easiest to just try rather than read about. The Demo page has real data already loaded and ready to drag in — including a file pair set up specifically to show the diff tool at work. Or jump straight into the tool with your own.

Recast — your private data workbench. Your data doesn't leave your browser. Your workflow can.
