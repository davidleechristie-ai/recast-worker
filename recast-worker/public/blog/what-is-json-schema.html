What Is JSON Schema?

JSON Schema is a way to describe the shape your data is supposed to have — which fields must be present, what type each one is, and what values actually count as valid. It's the difference between "this is JSON" (just syntactically well-formed) and "this is JSON that looks like a real customer record" (matches a specific, checkable shape).

A real, generated example

Given this sample data:

[
  {
    "name": "Ada Lovelace",
    "role": "Engineer",
    "age": 36
  },
  {
    "name": "Grace Hopper",
    "role": "Admiral",
    "age": 85
  }
]

Recast's Schema Generator produces this — a genuine, working output, not a simplified example:

{
  "$schema":
    "http://json-schema.org/draft-07/schema#",
  "title": "Person",
  "type": "array",
  "items": {
    "type": "object",
    "properties": {
      "name": { "type": "string" },
      "role": { "type": "string" },
      "age": { "type": "integer" }
    },
    "required": [
      "name", "role", "age"
    ]
  }
}

What that schema actually lets you check

Once you have a schema, you can validate any future data against it. Say a bad record comes through — an age field that's negative:

{
  "name": "Ada Lovelace",
  "age": -5
}

Against a schema with "minimum": 0 on the age field, Recast's validator reports exactly what's wrong and where — genuine output, not paraphrased:

{
  "valid": false,
  "errors": [
    {
      "path": "age",
      "message": "must be >= 0"
    }
  ]
}

That's the actual value of a schema: not just "is this valid JSON," but "does this data mean what it's supposed to mean."

What's covered, honestly

Recast's schema tools implement a genuinely useful subset of JSON Schema draft-07 — type, enum, const, properties, required, additionalProperties, items, minItems, maxItems, numeric bounds (minimum, maximum, and their exclusive variants), string length and pattern, and anyOf, oneOf, allOf. That covers real API-contract checking for the large majority of everyday cases. It isn't a full implementation of every draft-07 keyword (or later drafts like 2019-09 or 2020-12) — if you need the complete specification, a dedicated library like Ajv is the right tool; Recast's version is built for fast, in-browser checking without that dependency.
