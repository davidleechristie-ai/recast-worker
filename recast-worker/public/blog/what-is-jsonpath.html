What Is JSONPath?

JSONPath is a way to point at exactly one piece of data inside a larger JSON document, without writing a loop to find it yourself. If you've ever gotten back a huge API response and just needed one field out of it, JSONPath is the tool for that specific job.

The basic idea

A JSONPath expression always starts with $, which just means "the whole document." From there, you walk down into it the same way you'd describe the path out loud: "the customers list, the first one, its name."

Three real examples

These are genuine, working queries — run directly against Recast's own JSONPath engine, not simplified for the page. Given this sample data:

{
  "customers": [
    { "name": "Ada Lovelace", "email": "ada@example.com" },
    { "name": "Grace Hopper", "email": "grace@example.com" }
  ]
}

1. Get one specific value

$.customers[0].name

Returns: "Ada Lovelace" — the first customer's name specifically.

2. Get the same field from every item

$.customers[*].email

Returns: ["ada@example.com", "grace@example.com"] — the [*] wildcard means "every item in this list."

3. Get a value from a specific position further in

$.customers[1].name

Returns: "Grace Hopper" — index [1] is the second item (indexes start at 0).

What this covers, honestly

Recast's JSONPath tool supports dotted keys, numeric array indices like [0], and the [*] wildcard — the three building blocks above cover the large majority of everyday "just get me this one thing" queries. It does not currently support the more advanced parts of the JSONPath specification some other implementations offer, like recursive descent ($..) or filter expressions ([?(...)]). If your query needs those specifically, that's worth knowing before you start.

When to reach for this instead of Find & Inspect's search

If you know the exact shape of your data and want the same field every time, JSONPath is precise and fast. If you're not sure where something lives in a large or unfamiliar document, Find & Inspect's plain-text search is often the quicker starting point — you can always turn what you find into a JSONPath expression once you know the shape.

Try it: Open the JSONPath Tester and run these same three examples yourself, or paste in your own data.
