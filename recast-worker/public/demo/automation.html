Guided product demo

Make the workflow run without you.

Automation is for repeatable jobs that should continue when your browser is closed: fetch an HTTPS input, execute the saved workflow, deliver the result to a webhook and keep enough history to understand what happened.

01ScheduleHourly, daily or weekly execution.
02FetchUse fixed input or a public HTTPS source.
03AuthenticateAttach an encrypted Bearer or API-key credential.
04DeliverSend the result to an optional HTTPS webhook.
05MonitorHistory, retries, usage and failure alerts.

Timezone-aware schedules

Daily and weekly schedules can use an IANA timezone such as Europe/London.

Failure handling

Execution and delivery can be retried up to three times; exhausted failures can trigger an email alert.

Usage controls

Automation tracks scheduled runs separately and enforces active-workflow and monthly-run limits.

Automation stores only what you explicitly configure

Automation configurationSchedules, input URLs, webhook destinations and optional fixed input are stored because the workflow must run when your browser is closed.
CredentialsBearer tokens and API-key values are encrypted at rest using the dedicated credential vault. The UI returns metadata, not the stored secret value.
