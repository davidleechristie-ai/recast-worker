Scheduled data transformation

Use a workflow when several data operations belong together, then move to hosted Automation only when that workflow must run without an open browser.

Design the transformation

Start with browser tools such as Flatten JSON, conversion tools, JSONPath or validation, and assemble the repeatable sequence in the Workbench.

Schedule it deliberately

Recast Automation is the hosted execution path for schedules and webhooks. Unlike browser-tool runs, hosted execution sends the input for that run to Recast for server-side processing.

Keep the boundary clear

Creating a workflow does not itself upload pasted source data. Moving to Automation is an explicit configuration step, with the hosted-processing distinction shown before the user proceeds.
