Automated data validation

Use Recast when the same validation needs to happen more than once: payload checks before imports, JSON syntax checks, or JSON Schema validation as part of a repeat process.

Check a payload locally

Use the JSON Validator or JSON Schema Validator for immediate browser-based checks.

Turn the check into a workflow

Build a repeatable sequence in the Workbench so validation can sit alongside conversion, transformation or extraction steps.

Run outside the browser

For scheduled validation, webhook-triggered checks or system-to-system use, choose Automation or the API. Those hosted runs send the supplied input to Recast for server-side processing.
