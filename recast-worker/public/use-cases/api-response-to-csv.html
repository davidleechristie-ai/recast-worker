API response to CSV

When an API gives you nested JSON but the next step is Excel, Sheets or a CSV-based import, use Recast to convert the captured response without writing a one-off script.

Start locally

Paste the response into the API Response to CSV tool. Browser-tool processing stays in the tab; the pasted payload is not sent to Recast for processing.

When it becomes repeat work

Use the post-success workflow path to carry the operation and its categorical settings into the Workbench. The input itself is not transferred by the handoff.

When you need hosted execution

For server-side or scheduled processing, use Automation or the Recast API. Hosted runs necessarily send the input to Recast for processing, so this is an explicit step beyond the private browser tool.
