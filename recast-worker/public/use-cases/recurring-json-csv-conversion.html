Recurring JSON/CSV conversion

If you keep repeating JSON → CSV or CSV → JSON with the same options, the useful next step is not another script: it is a reusable workflow that remembers the operation.

One-off first

Use JSON to CSV or CSV to JSON in the browser. Nothing needs to be uploaded for the local tool run.

Reuse the operation

After a successful conversion, Recast can start a Workbench workflow using the selected operation and categorical settings. Pasted source data is not copied into the handoff.

Run it unattended

If the job must run on a schedule or from another system, move deliberately to hosted Automation or the API. Hosted execution processes the supplied input server-side.
