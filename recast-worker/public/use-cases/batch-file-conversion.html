Batch file conversion

When the operation is the same but the files change, batch processing is usually more useful than repeatedly pasting each file into a one-off tool.

Start with one file

Confirm the transformation in a free browser tool such as JSON to CSV or CSV to JSON.

Move to batch

Recast Pro adds batch tooling for supported modes and higher file limits. This remains a browser-side workflow where the selected files are handled locally by the tool.

Beyond local batch

If files arrive automatically or processing needs to run unattended, use Automation or the API. Those hosted paths process supplied input server-side.
