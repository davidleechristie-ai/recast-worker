What is Recast?

Data often comes in formats that are difficult to read or use. An API might give you thousands of lines of JSON. A spreadsheet might contain inconsistent data. A supplier might send XML. Two versions of a dataset might look almost identical but contain important differences.

Recast gives you one place to inspect, change, check, compare and automate that data.

No coding required for most tasks.

Beginner → power user

Nobody needs to learn all of this at once. Here's the order most people naturally grow into it:

1

First file

Paste, pick a mode, hit Convert. That's it.

2

Understand before you trust it

Open Data Inspector to see what's actually in a file before acting on it.

3

Reshape it

Transform Builder for the fields you actually need, renamed and cleaned up.

4

Stop repeating yourself

Save the steps you keep reusing as a Recipe.

5

Wire it into something else

Call the same recipe from the API or CLI — no more manual copy-paste, ever.

Real-world examples

A config file that's painful to hand-edit as JSON — YAML is common for service configs. Convert it to JSON to edit programmatically, then back to YAML to deploy:

replicas: 3 resources: cpu: "500m" memory: "256Mi"

Catching a breaking API change before it ships — a field that changes type is a real problem for anything reading it:

Before
{ "age": 42 }
After
{ "age": "42" }

Number → string. Structural Analysis flags this as Breaking — anything expecting a number to do math on it just got a string instead.

These aren't toy examples — the Demo page runs the exact same Compare tool against a real 400-order dataset with 225 genuine changes between two versions, not three made-up rows.

Is my data safe?

A fair question, especially with something like a customer list. Short answer: yes. Conversion happens entirely on your own device, inside your browser — nothing is uploaded, logged, or stored.

The one exception: using the API to connect Recast to your own software means that specific request does go to our server to be processed — but a one-off paste-and-convert in your browser never leaves your machine.

Ready to start? Open the tool with your own file, or try it with a real sample if you don't have one handy. Not sure where to begin? Jump back to "which problem are you solving".
