Convert data

The most common thing people use Recast for: turning one format into another. Say you exported your customer list from an online store as a spreadsheet (CSV), but the system you need to send it to only accepts JSON.

Before — CSV
id,name,city 1,Ada Lovelace,London 2,Grace Hopper,New York
After — JSON
[ { "id": 1, "name": "Ada Lovelace", "city": "London" }, { "id": 2, "name": "Grace Hopper", "city": "New York" } ]

Same three customers, same information — just written in the shape the receiving system can actually understand. Here's how to do that with your own file:

1

Pick what you have and what you want

A row of plain-English buttons like "JSON → CSV" or "CSV → JSON" (the arrow means "turns into"). Nothing is saved or sent anywhere until you say so, and you can change your mind any time.

2

Paste or upload, then Convert

Paste your file into the left box, or click "Upload" to pick it straight from your computer. Click the yellow Convert button and your result appears on the right almost instantly.

3

Copy it or download it

Copy pastes the result straight into another program; Download saves it as a real file. That's the whole process.

Try it: Open Convert with the mode picker ready, or load a real sample file if you don't have one handy.

Turn data into the format you need

Different systems use different data formats. Recast lets you convert between formats without writing a script.

JSON → CSV

Before
{
  "name": "Sarah",
  "age": 32,
  "active": true
}
After
name,age,active
Sarah,32,true

CSV → JSON

Before
name,age,active
Sarah,32,true
After
[
  {
    "name": "Sarah",
    "age": 32,
    "active": true
  }
]
Try it →

JSON → XML

Before
{
  "name": "Sarah",
  "age": 32,
  "active": true
}
After
<person>
  <name>Sarah</name>
  <age>32</age>
  <active>true</active>
</person>

XML → JSON

Before
<person>
  <name>Sarah</name>
  <age>32</age>
  <active>true</active>
</person>
After
{
  "person": {
    "name": "Sarah",
    "age": "32",
    "active": "true"
  }
}
