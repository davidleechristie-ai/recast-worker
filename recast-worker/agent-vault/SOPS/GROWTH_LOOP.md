# SOP — Autonomous £1K growth loop

1. Read AGENTS.md, PRODUCTS/RECAST.md, OPS/CURRENT_STATE.md, ../GROWTH_SCOREBOARD.json and latest relevant ../AUTONOMOUS_GROWTH_LOG.md.
2. Refresh evidence available through connected tools: genuine revenue, Search Console, GA4/product events, production health. Unavailable = null.
3. Build funnel: acquisition → activation → deeper use → commercial intent → paid conversion.
4. Identify the earliest stage with sufficient evidence of a bottleneck.
5. Check active experiments/fixed review dates; do not overlap that stage.
6. Fix P0/P1 first. Otherwise define one falsifiable experiment with baseline, expected signal and review date.
7. Implement the smallest test of the hypothesis.
8. Run tests and, for UI/deployment, SHIP_PRODUCT_CHANGE.md.
9. Deploy only when justified and gates pass.
10. Verify production/instrumentation.
11. Update CURRENT_STATE.md and the existing growth ledger.
12. Next run: measure before changing anything else.

Success is genuine recurring revenue, not activity volume.
