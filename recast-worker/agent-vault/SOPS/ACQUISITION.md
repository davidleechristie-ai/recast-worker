# SOP — Acquisition

Use Search Console to distinguish indexing, ranking and CTR problems. Prefer problem/workflow intent that leads naturally to Recast's repeatable-pipeline value.

Before SEO edits check the growth ledger for an active experiment and fixed review date. Never layer a new SEO experiment over an active one merely because results are slow.

Record page/query baseline, hypothesis, exact change, expected signal, start date and fixed review date. Measure at the window before keep/revert/replace.
