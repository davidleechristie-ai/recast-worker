# SOP — Activation and conversion

Activation means a visitor gets useful output and understands it can become a repeatable pipeline. Analytics must be privacy-safe: never send prompt/data/file contents or field values.

If activation is earliest: inspect landing/tool → successful use → pipeline build → pipeline run and remove the first friction.
If commercial intent is earliest: inspect successful/deeper use → save/automation/API/pricing intent and surface paid value when it solves a demonstrated need.
If paid conversion is earliest: verify checkout links, entitlements, successful-payment/refund measurement and post-purchase path before changing pricing/copy.
