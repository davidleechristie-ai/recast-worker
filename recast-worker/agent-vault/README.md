# Recast OpenAI Agent Vault

Repository-native Markdown memory for an OpenAI-powered Recast operator. ChatGPT/Work, an OpenAI coding agent, Cursor using OpenAI models, or an OpenAI Agents/Responses API runner can load only the notes needed for the task.

Start with AGENTS.md, PRODUCTS/RECAST.md and OPS/CURRENT_STATE.md, then load the relevant SOP. Quantitative experiment truth remains in ../GROWTH_SCOREBOARD.json and ../AUTONOMOUS_GROWTH_LOG.md.

Store process and decisions here, never secrets or customer data.
