# Recast

Recast is a browser-based developer data workbench for fixing, transforming, inspecting, comparing, validating and automating JSON/CSV/XML/API data.

## Core journey
data → describe outcome → visible deterministic pipeline → result → save/repeat → automate/API.

## Audience and job
Developers/technical users who otherwise write throwaway scripts, chain web tools or repeatedly repair the same data.

## Differentiation
One coherent repeatable workflow; visible deterministic transformations; privacy-first browser processing where suitable; progression from free tool to workflow, Automation and API.

## Commercial
Free acquisition tools feed paid Pro/Automation/API value. Count revenue only from verified successful non-refunded payments.

## Product direction
Recast 2 makes the pipeline the product. Reuse the existing deterministic engine and workflow machinery instead of creating parallel systems.
