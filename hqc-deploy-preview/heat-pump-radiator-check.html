Independent heat-pump quote guidance

Check the radiator assumptions in a heat pump quote

Radiator changes can materially affect the price and performance assumptions in a heat-pump proposal. The important question is not whether every radiator is replaced, but whether each room has enough emitter output at the intended design temperature.

Start with room heat loss

The radiator requirement should be linked to the heat loss of each room, not just the total property heat loss.

Check output at the proposed flow temperature

Radiator output falls as water temperature falls. Ask the installer to show the output used at the proposed heat-pump design condition.

Separate existing and proposed emitters

A clear quote should identify which emitters stay, which change, and the size or type of each proposed replacement.

Look for assumptions

If radiator suitability is marked subject to survey or based on estimated room dimensions, treat that as an unresolved assumption.

Compare like for like

When comparing installers, make sure differences in radiator scope are not being mistaken for differences in heat-pump price alone.

Ask for the schedule

Request the room-by-room emitter schedule alongside the heat-loss calculation so the design logic can be checked.
