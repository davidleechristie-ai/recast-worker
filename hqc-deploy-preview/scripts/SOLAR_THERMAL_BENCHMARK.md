# Solar thermal evidence benchmark

Run `node scripts/solar-thermal-benchmark.mjs private-benchmark/solar-thermal.json` from `hqc-deploy-preview`. The input folder is ignored by Git. The command prints aggregate counts only and exits nonzero until the real-quote gate passes. Do not commit source quotes, personal information, or the private corpus.

Each JSON case in `{"cases":[...]}` needs a unique `id`, `quoteText`, `sourceType` (`synthetic` or `permissioned_real`), pseudonymous `installerKey`, `layoutKey`, `permissioned`, `deidentified`, and a complete `expected` object. Before marking a quote real, obtain permission for this use, remove names, addresses, contacts, account numbers and other identifying details from the text, and have a human check the redaction and labels. Keep the original and permission record in the approved source system. `permissioned:true` and `deidentified:true` are reviewer attestations; the script cannot verify them. Use distinct source documents for distinct case IDs and a stable pseudonym for each installer. `layoutKey` denotes a materially different document format, not a renamed copy.

The exact expected keys are `collectorType`, `collectorAreaM2`, `cylinderLitres`, `annualSolarHeatKwh`, `priceGbp`, `backupHeat`, `occupants`, `hotWaterLitresPerDay`, `roofMountingScope`, `scaffoldingScope`, `pipeworkScope`, `pumpControlsScope`, `commissioningScope`, `collectorWarrantyYears`, `cylinderWarrantyYears`, `workmanshipWarrantyYears`. All keys are required. Set an absent, ambiguous or uncommitted value to `null`; do not omit it. Use `flat_plate` or `evacuated_tube` for collector type, `included` for explicit backup integration, and `included`, `excluded` or `conditional` for scope. Use numbers for quantities, years and price. Annotate only the selected final price, not optional or historical alternatives.

The public accuracy gate requires at least 30 independent contemporary permissioned real quotes from five installers and two layouts; three explicit positive labels for every material field; at least 95% exact match recall on stated fields; and zero invented values where the label is unknown. Synthetic examples can exercise the harness but cannot satisfy the gate. The report intentionally contains no case IDs, quote text, or installer identifiers. This is the extractor gate only: technology-specific commercial copy and a public-host purchase and PDF journey still require their separate release checks. Until the real corpus meets the gate, Solar thermal remains private.
