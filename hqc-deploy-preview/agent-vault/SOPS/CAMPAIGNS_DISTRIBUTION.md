# SOP — Campaigns and distribution

Define one consumer/installer/referral audience and one measurable journey into the checker. Prefer low-touch channels: search-led content, useful checklists/tools, shareable Decision Cases, installer referral pages/QR links, owned social or opted-in messaging when authorised. Create one hypothesis, asset set, landing path and commercial event. Never fabricate savings, customer outcomes or urgency. Execute through connected authorised tools where available, measure genuine traffic/actions, exclude tests, and log keep/modify/stop learning.
