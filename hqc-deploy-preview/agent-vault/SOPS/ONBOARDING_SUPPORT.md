# SOP — Onboarding and support

Map arrival → single/compare choice → upload/manual entry → analysis → next action. Use observed failures/feedback to find earliest friction. Keep language consumer-friendly and explain what the service can and cannot determine. Prefer fixing self-service UX over adding support burden. Do not collect extra personal information merely to make support easier. Instrument privacy-safe milestones and turn repeated issues into product fixes/FAQ only when evidence supports them.
