# SOP — Acquisition and conversion

Use measured search/referral/traffic evidence to distinguish visibility from CTR/landing problems. Research current intent/competitors before creating acquisition content; no thin programmatic SEO. Respect active SEO measurement windows.

For conversion inspect the journey acquisition → checker start → quote upload/manual entry → genuine analysis → comparison/Decision Case → share/commercial action → genuine purchase. Remove the earliest measured friction and instrument privacy-safe events. Never fabricate demand, testimonials, ROI, signals or urgency. Verify checkout/payment success and post-purchase path before interpreting conversion.
