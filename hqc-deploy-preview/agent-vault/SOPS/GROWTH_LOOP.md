# SOP — Revenue growth loop

1. Read AGENTS.md, PRODUCT.md, CURRENT_STATE.md and latest RUN_LOG.md.
2. Refresh genuine revenue, funnel/product events, acquisition evidence and production health available through connected tools. Unknown = null.
3. Map acquisition → checker start → quote upload/manual entry → genuine analysis → comparison/Decision Case → share/commercial action → genuine purchase.
4. Identify the earliest material measured bottleneck.
5. Check active experiments so changes do not contaminate attribution.
6. Fix P0/P1 first; otherwise define one falsifiable experiment for the affected stage with baseline, expected signal and review point.
7. Implement the smallest high-value intervention. While evidence matures, progress independent non-confounding stages rather than waiting.
8. Test and follow SHIP_CHANGE.md for releases.
9. Verify production and instrumentation.
10. Write evidence and learning back to CURRENT_STATE.md and RUN_LOG.md.

Success is genuine revenue and durable customer value, not activity volume.
